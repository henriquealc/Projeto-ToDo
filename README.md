# 📝 EasyTask

> ✅ Organize suas tarefas de forma simples, rápida e prática

---

## 💡 Sobre o projeto

O **EasyTask** é uma aplicação de lista de tarefas (ToDo List) desenvolvida para praticar conceitos básicos de front-end.

### 📚 O que foi praticado:

- 📌 Manipulação do DOM  
- 💾 Uso do LocalStorage  
- 🎨 Estilização com CSS  
- 📱 Responsividade com Media Queries  

---

## ⚙️ Funcionalidades

- ➕ Adicionar tarefas  
- ✏️ Editar tarefas  
- 🗑️ Excluir tarefas  
- ✅ Marcar como concluída  
- 🔍 Buscar tarefas  
- 💾 Salvamento automático no navegador  

---

## 🖥️ Tecnologias utilizadas

- 🌐 HTML5  
- 🎨 CSS3  
- ⚙️ JavaScript  
- ⭐ Font Awesome (ícones)  

---

## 📱 Responsividade

O projeto foi pensado para diferentes tamanhos de tela:

- 📱 Mobile  
- 💻 Desktop  
- 🖥️ Telas grandes  

---

📌 Observações
- 💾 Os dados são salvos no LocalStorage
- 🌐 Não precisa de internet
- 🎓 Projeto feito para estudo
